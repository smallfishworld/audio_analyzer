# Audio Analyzer v0.1.0-preview.2 — Waveform and Spectrogram Fixes

**预览修复版**，基于首版 `v0.1.0-preview.1` 的全部分析、STFT 与只读试听能力，专门修复长时纯音出现整块波形和整块蓝色 STFT 的问题。

## 主要修复

- **真实采样波形**：以 32 kHz/4 kHz/0 dBFS/60 s 正弦波为基准，初次导入密集纯音时自动打开约 16 ms 的真实采样窗口；上方仍保留完整 60 秒的导航概览。
- **采样级缩放**：新增 `Samples` 快捷操作、8 帧极限放大。局部独立的 `waveform_samples` 后端每次最多读取 65,536 帧，保留 f32/f64 PCM 超过 ±1 的原始幅值，不复用试听裁剪接口。根据视图规模在样本折线和每像素 min/max 之间切换。
- **全局概览**：长文件 min/max 包络不再采用高饱和实心填充，并明确提示密集概览不等于原始波形周期。
- **时频谱 STFT**：使用深色 -120 dBFS 噪声背景和亮色纯音谱线，添加 dBFS 色标、频率/时间悬停读数，并修正 256 行压缩频率映射的取整误差。
- **布局与交互**：修复中央 Flex 导致时频谱被压缩、裁剪和鼠标点击被邻近控件遮挡；改为保持面板正常高度并在中央滚动。
- **频谱细节**：去除频谱面积填充，突出主要频率，屏蔽 -100 dBFS 一类的数值旁瓣杂峰。

## 测试

Rust 使用真实生成的 60 秒 32 kHz/4 kHz s16 PCM（1,920,000 帧）验证 Peak、RMS、FFT、STFT 行定位、独立采样读取，另验证浮点超幅值不受试听限幅影响。Playwright 测试检查毫秒周期波形与深色 STFT，并保留原有文件/选区/声道/播放 UI 回归。

## 已知限制

- 全局概览不可能在约 900 像素内显示 240,000 个 4 kHz 周期；必须放大到毫秒或采样级。
- 高级分析选区单次 2,097,152 帧；波形按需窗口单次 65,536 帧，不是任意长度全量加载；多级持久 LOD 缓存未实现。
- 数字电平单位 dBFS，未提供声学 dB SPL 校准；STFT 热力图不是 PSD。
- 压缩格式的默认概览仍可能只含前三秒；随机片段可按需分析，精确定位取决于格式。
- Windows 未签名；macOS ad-hoc 签名且尚未公证。CI 及浏览器模拟测试无法替代 Windows/macOS 原生图形与实际声卡验收。

## 发布要求

Windows NSIS、macOS Intel/Apple Silicon DMG 和 Rust/前端/编解码/UI 自动测试必须在**同一 Git SHA**成功，三份安装包与 SHA256SUMS.txt 校验齐全后由 Actions 创建预发布。工作流不会覆盖旧 tag，也不会将过时 main commit 误发布为最新版本。
